// HashMap Notes : 

// A HashMap is a data structure that stores data in key-value pairs, where each key is unique and is used to quickly 
access its corresponding value.

Stores: Key → Value
Keys cannot be duplicate
Average time complexity for put() and get() is O(1)
Does not maintain insertion order

Hashset can be used for Array, string, Linkedlist and with any other data structure. Where you want unique elements or 
fast searching.

Words → HashSet<String>
