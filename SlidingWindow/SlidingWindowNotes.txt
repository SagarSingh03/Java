Sliding Window is a DSA technique used mainly with arrays and strings to solve problems faster.
Instead of checking every possible subarray again and again, we use a window that moves (slides) through the array.
Think of it like this:
Array: [1, 2, 3, 4, 5]
Window size = 3
[1, 2, 3]  -> move
   [2, 3, 4] -> move
      [3, 4, 5]
The window keeps sliding one step at a time.
Usually improves complexity from:

O(n2)→O(n) 
*******************************************************************************************************

Why Do We Use Sliding Window?
Without sliding window:
Many problems take O(n²) time.
With sliding window:
They become O(n) time.
So it makes code much faster.
It reduces unnecessary repeated computations.
Instead of:
calculating every subarray again and again,
we:
reuse previous calculations while moving the window. This makes solutions faster and more optimized.

******************************************************************************************************
Types of Sliding Window
There are mainly 2 types:
Fixed Size Window
Variable or Dynamic Size Window

*****************************************************************************************************
1. Fixed Size Sliding Window
Window size is already given.
Example:
Find maximum sum of subarray of size k.
Normal Brute Force
For every subarray:
calculate sum again
Time Complexity = O(n²)
******************************************************************************************************
Sliding Window Idea
Instead of recalculating:
Old Window = [1,2,3] sum = 6
Next Window:
remove 1
add 4
New sum = 6 - 1 + 4 = 9
Very fast.
Example
Array
[2,1,5,1,3,2]
k = 3
Find maximum sum of size 3.
Step-by-Step
First window:
[2,1,5] = 8
Slide:
remove 2
add 1
sum = 8 - 2 + 1 = 7
Slide:
remove 1
add 3
sum = 7 - 1 + 3 = 9
Slide:
remove 5
add 2
sum = 9 - 5 + 2 = 6
Maximum = 9

******************************************************************************************************

2. Variable Size Sliding Window
Here window size changes.
Used when problem says:
longest
smallest
maximum length
minimum length
unique characters
target sum

Main Idea
We use 2 pointers:
left
right
Window is:
[left ... right]
expand window → move right
shrink window → move left
Example
Problem
Find longest substring without repeating characters.
String:
"abcabcbb"
Answer:
"abc"
length = 3
How It Works

Start:
a
ab
abc
Now next is a again.
Duplicate found.
Move left pointer until duplicate removed.
Then continue.

*******************************************************************************************************
Fixed vs Variable Window:
| Feature     | Fixed           | Variable          |
| ----------- | --------------- | ----------------- |
| Window size | Fixed           | Changes           |
| Example     | size k          | longest substring |
| Pointers    | Mostly one loop | left + right      |
| Difficulty  | Easy            | Medium            |

****************************************************************************************************

4. What is the Main Idea Behind Sliding Window?
Answer:
Maintain a range/window using pointers.
expand the window when valid
shrink when invalid
update answer during traversal

****************************************************************************************************

10. Why is Sliding Window Better Than Brute Force?
Brute force:
recalculates repeatedly
often takes O(n²)
Sliding window:
reuses previous work
reduces repeated operations
often becomes O(n)

**************************************************************************************************

14. What Happens When Window Becomes Invalid?
We shrink the window by moving left pointer until it becomes valid again.
This is the core idea in variable-size windows.

*****************************************************************************************************
15. Can Sliding Window Work on Unsorted Arrays?
Yes.
Unlike some two-pointer problems, sliding window does NOT require sorting in many cases.
Especially:
substring problems
frequency/count problems
